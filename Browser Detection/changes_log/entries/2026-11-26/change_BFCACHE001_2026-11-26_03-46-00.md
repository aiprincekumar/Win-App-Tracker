## Root Cause & Fix
1. **Root Cause:** When pages entered Chromium Back/Forward Cache (`bfcache`), MV3 closed `sentinel_tracking_keepalive` ports and fired `port.onDisconnect` with `runtime.lastError` ("The page keeping the extension port is moved into back/forward cache, so the message channel is closed."), while several `onDisconnect`, `sendMessage`, `tabs.sendMessage`, `tabs.query`, and `sendNativeMessage` sites did not safely consume `runtime.lastError` or handle Promise rejections.
2. **Fix:** Added `consumeRuntimeLastError()` across `timestamp_reconciliation.js`, `safe-messaging.js`, and `content_media.js`; drained `runtime.lastError` on all `onDisconnect.addListener` and IPC callbacks; added `isPageInBfcache` freeze gating on `pagehide` (`persisted`) / `pageshow` (`persisted`) in `content_media.js`; wrapped `LAUNCH_DESKTOP_HUD` and `LAUNCH_DATA_HUB` `sendNativeMessage` callbacks in `try/catch`; and hardened Popup/Dashboard/Bridge messaging helpers.
3. **Audit & Regression:** Verified 0 diff lines in `commitBackgroundMediaDelta`, `trackMediaSession`, `finalizeMediaSession`, `activeMediaSessions` loops, and `src/background/telemetry/domain_tracker.js`; authored 5-battery `tests/test_bfcache_port_lasterror_regression.js` (`321` lines); aligned `tests/test_media_controls_and_fullscreen_fix.js`; certified **130/130 PASSED** (`node run_all_tests.js`, `37.29s`, Exit Code `0`), `node --check` PASS, UTF-8 BOM PASS, and `gitleaks` `0` leaks.
